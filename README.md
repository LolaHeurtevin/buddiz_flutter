# buddiz

Buddiz est une application qui permet à des utilisateurs de proposer et participer à des activités près d'eux.

## Fonctionnalités
- Onboarding
- Carte interactive affichant les activités
- Liste des activités
- Page présentant une activité
- Formulaire d'ajout d'activité

## Architecture du projet
Le projet suit une architecture MVC, les dossiers principaux sont :
- controllers
- models
- services
- utils
- views

## Commandes utiles
### Lancer le projet
flutter run
